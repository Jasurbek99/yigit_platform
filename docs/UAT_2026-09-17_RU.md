### Завтра: программа

| Время | Что |

### Что сказать на вступлении (5 пунктов)

1. Цель: понять, можно ли вести вашу ежедневную работу в платформе вместо Excel.
2. Работаем на **настоящих** данных. Не уверен, сохранять ли? Спроси ведущего.
3. Любая проблема или идея → **кнопка справа внизу** → «Ошибка / Предложение / Вопрос» +
   скриншот. Пишите сразу, не копите до разбора.
4. Excel сегодня ведём как обычно.
5. Пароль не подходит? После **второй** ошибки остановитесь и позовите ведущего.

### Известные ловушки (это не ошибки, предупредить заранее)

- **Босс не видит галочки у строк**, пока не переключит шапку с «Просмотр» на «Редактирование».
  Иногда нужно ещё раз обновить страницу.
- **Новый рейс создаётся как черновик.** Чтобы перевести его дальше, нужно закрыть задачи
  подготовки, назначить страну и клиента и нажать «Перевести в «Таможня ТМ вход»». Если кнопка
  неактивна, проверить открытые задачи.
- **«Мои задачи» (`/me/board`):** клик по карточке открывает боковую панель, а не страницу рейса.
  Ссылка на рейс внизу панели.
- **Seller** на странице «Квоты» видит только таблицу местных продаж. Так и задумано.
- **Менеджер теплицы** не видит «Отгрузки». Так и задумано.
- **Пустая неделя в «План недели»** открывается только после кнопки «Создать неделю».
  В таблице местных продаж эта кнопка называется «Инициализировать неделю». Кнопка сразу создаёт
  строки для всех блоков, и отменить это нельзя. Нажимать только для недели, которую реально
  планируете.
- **«Сегодня» считается по времени Ашхабада**, а не по часам ноутбука.

### Во время теста

- Хотфикс во время теста только для **блокера**, когда отдел вообще не может работать. Всё
  остальное после теста.
- Если платформа легла: все переходят в Excel, ведущий смотрит `docker compose ps` и логи бэкенда.
- Если испорчены данные: не восстанавливать бэкап сразу. Сначала выяснить масштаб: восстановление
  откатит и настоящую работу, сделанную за день.

### После теста

1. Каждое сообщение в `/admin/feedback` отнести к одной из групп: **блокер / ошибка / хотелка /
   вопрос-обучение**.
2. Ответы на вопросы отмечать как публичные, чтобы их видели все (`/feedback/public`).
3. Для каждого отдела решить: готов работать в платформе / нужны доработки (какие).
4. Блокеры и ошибки войдут в следующий деплой вместе с веткой `Copy_Gadams_UI`.

## Часть 2. Карточки участников

> Общее для всех: делайте свою обычную работу дня в платформе. Проблема или идея →
> **кнопка справа внизу**. Свои задачи: **«Мои задачи»** (`/me/board`).

### Экспорт-менеджер

- Черновики → назначение направления (**Черновики**, **Назначить**)
- **Лист**: заполнить свои колонки по сегодняшним рейсам
- Карточка рейса: статусы, комментарии
- **Квоты**, **План недели**
- Проверить: всё ли, что вы ведёте в Excel, есть в «Листе»?

### Документы

- **Лист**: колонки документов и таможни по сегодняшним рейсам
- **Контракты**, **Документы**: создать/скачать документ по настоящему рейсу
- **Экспортные фирмы**, **Сезоны**: справочники
- Проверить: скачанный документ совпадает с тем, что вы делаете вручную?

### Директор / Босс

- **Босс панель**, **Главная**: цифры дня сходятся с Excel?
- **Авансы**, **Цены**, **Просрочено**, **Зависшие отгрузки**
- **Рейтинг команды**
- Босс: для правок переключить шапку с «Просмотр» на «Редактирование»

### Начальник погрузки / заместитель

- **Черновики**: создать черновики на сегодняшние машины из блоков
- **Лист**: колонка поставки (блоки, вес)
- **План груза и остаток**
- **Управление блоками**
- Проверить: остаток по блокам совпадает с реальностью?

### Склад

- **Отгрузки**, **Черновики**: сегодняшние машины
- **План груза и остаток**
- Паллетный лист рейса (из карточки рейса)

### Весовщик

- **Весовщик**: внести/загрузить взвешивание по сегодняшним машинам
- **План груза и остаток**
- Проверить: веса по блокам совпадают с вашим журналом?

### Менеджер теплицы

- **План недели**: план по своим блокам на эту и следующую неделю. «Создать неделю» нажимать
  только для недели, которую реально планируете: отменить нельзя
- **Внутр. продажи**
- Проверить: вы можете править только свои блоки?

### Транспорт

- **Отгрузки**, **Доска**: сегодняшние машины
- **Карта автопарка**: где машины сейчас?
- **План груза и остаток**

### Финансист

- **Авансы**: внести сегодняшние авансы
- **Цены**: проверить/обновить цены
- Проверить: суммы сходятся с Excel?

### Бухгалтер

- **Главная**, **Отгрузки**, **План груза и остаток**: только просмотр
- Главный вопрос: каких данных вам не хватает для работы?

### Торговый представитель (sales_rep)

- Отчёты о продажах по своим рейсам (`/export/my-reports`)
- **Отгрузки**: свои рейсы
- Проверить: отчёт заполняется без Excel?

### Продавец (seller)

- **Квоты** → таблица местных продаж: внести план на неделю
- Проверить: всё, что вы ведёте, помещается в эту таблицу?
