# Обмен данными рейса: пакет для разработчиков внешней программы

**Версия контракта: 1.0-draft. Редакция: 2026-09-28.**

## Что это

Черновик контракта обмена между нашей системой планирования рейсов и вашей программой.
Swagger вашей стороны нам недоступен, поэтому контракт составили мы — по требованиям
заказчика — и передаём его вам **на согласование**. Замечания и встречные предложения
ожидаются: это черновик, а не утверждённый интерфейс.

Ни один маршрут пока не реализован. Контракт проверен у нас локально на симуляторах:
47 проверок, все пройдены. С вашей стороной он ещё не сверялся.

| Файл | Что это |

Все примеры **вымышленные**: имена, номера машин, номера документов и телефоны не
принадлежат никому. Настоящих данных в пакете нет. Боевого ключа в пакете нет.

## Симулятор нашего API — одна команда

Чтобы вам не ждать нашей реализации, контракт можно поднять как рабочий сервис.
Нужен только Docker. Команда выполняется **из каталога этого пакета**.

```bash
docker run --rm -p 4910:4010 -v "$PWD:/spec:ro" stoplight/prism:5 mock --host 0.0.0.0 --port 4010 --errors --multiprocess false /spec/planning-integration-api.v1.yaml
```

Симулятор поднимется на `http://localhost:4910`. **Порт — 4910.**

Что он делает:

- проверяет ваш запрос по схеме контракта; несоответствие → `422`;
- проверяет наличие ключа; без него → `401`;
- отвечает примерами из контракта.

Чего он **не** делает: не хранит состояние. Повтор с тем же `Idempotency-Key` вернёт
тот же ответ, но `duplicate` останется `false`. Настоящая идемпотентность будет
в реализации.

### Заголовки

| Заголовок | Обязателен | Значение |
|---|---|---|
| `Authorization` | да | `Bearer <ключ>`. Для симулятора подойдёт **любая непустая строка**, например `Bearer test-key`. Боевой ключ выдаётся отдельно и в этот пакет не входит |
| `Idempotency-Key` | да, у всех `POST` | Ваш идентификатор операции; совпадает с `eventId` в теле |
| `X-Correlation-Id` | нет | Сквозной идентификатор для разбора инцидентов |

### Проверка одной командой

```bash
curl -i -X POST "http://localhost:4910/trips/6f1c2a3e-8f0b-4c7d-9a10-2b3c4d5e6f70/customs" -H "Authorization: Bearer test-key" -H "Idempotency-Key: EXT-2026-000107" -H "Content-Type: application/json" -d @examples/request-customs.json
```

## Операции

**Вы → мы** (вы присылаете сведения по рейсу):

| Операция | Что передаёт |
|---|---|
| `POST /trips/{id}/loading` | Город погрузки и место погрузки внутри города |
| `POST /trips/{id}/destination-city` | Город назначения |
| `POST /trips/{id}/cargo` | Продукт (вид груза) |
| `POST /trips/{id}/events` | Событие места погрузки: прибыл, загружен, убыл |
| `POST /trips/{id}/export-code` | Код экспорта. **Он же становится номером рейса** |
| `POST /trips/{id}/customs` | Прохождение таможни |
| `POST /trips/{id}/rejection` | Отклонение планируемого рейса с причиной |
| `GET /trips/{id}` | Чтение того, что мы знаем о рейсе |
| `GET /trips/{id}/document` | Лист A4 со сканами документов рейса (PDF) |

**Мы → вы** (мы шлём уведомления на ваш адрес):

| Уведомление | Когда |
|---|---|
| `tripCreated` | Рейс создан и передан как планируемый |
| `tripChanged` | Заменён тягач, прицеп или водитель |
| `tripCancelled` | Рейс отменён |
| `tripDocumentAvailable` | Готов лист A4; передаётся **ссылка**, файл не вкладывается |

Адрес вашего приёмника и способ аутентификации у вас — согласуем отдельно.

## Три правила, которые важнее остальных

1. **Рейс адресуется `integrationTripId` (UUID), а не номером.** Номер рейса меняется:
   до прихода вашего кода экспорта его вообще нет, потом он появляется, а присланный
   заново код его заменяет. UUID выдаётся один раз и не меняется никогда.
2. **Код экспорта и номер рейса — одно и то же поле.** Присылая код экспорта, вы
   задаёте номер рейса. Формат кода не задан и не проверяется. Коды уникальны:
   повтор чужого кода отклоняется с `DUPLICATE_EXPORT_CODE`.
3. **Завершённый рейс сведений не принимает.** Как только рейс закрыт либо отменён,
   любая запись отклоняется кодом `409` `TRIP_CLOSED`, и ничего не изменяется. Повторять
   бессмысленно: из этих состояний рейс не возвращается — снимайте операцию из очереди
   повторов. Чтение остаётся доступным: и состояние рейса, и лист A4 по завершённому рейсу
   по-прежнему выдаются.

## Доступно сейчас / Появится позже

Контракт описывает **целевой** состав обмена.

**Правило, которое важно для разбора ответов:** всякий реквизит из правой колонки объявлен
в контракте **необязательным** и **до включения приходит пустым** (`null`) либо отсутствует
в теле. Ни один такой реквизит нигде не описан как доступный. Реквизиты, объявленные
