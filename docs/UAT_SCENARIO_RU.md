# Сценарий теста с сотрудниками: одна машина через все отделы

**Для кого:** ведущий теста. Участники не программисты: они проверяют, можно ли делать свою
работу в платформе и проходит ли машина весь путь от теплицы до отчёта о продаже.
**Версия:** `main`. Сервер http://10.10.11.25:8080. База живая, всё сохранённое остаётся.
**Участники (7):** менеджер теплицы, экспорт-менеджер, отдел документов, начальник погрузки
(или заместитель), финансист, торговый представитель, транспорт.
**Компаньон:** [UAT_2026-09-17_RU.md](UAT_2026-09-17_RU.md) (подготовка сервера, карточки
отделов, программа дня).

**Два блока теста:**

1. **Одна машина через весь цикл** (часть 2 и 3): участники по очереди берут мышь, каждый делает
   свой шаг, все видят, как меняется статус. 60–75 минут.
2. **Своя работа дня** (часть 4): каждый на своём ноутбуке делает то, что обычно делает в Excel.
   45 минут, параллельно или после.

---

## Часть 1. Перед началом (ведущий, 15 минут)

1. **Логины.** Каждый участник входит под **своим** логином. Язык в шапке: RU или TM. Открыть
   **«Мои задачи»** и **«Лист»** (у менеджера теплицы вместо «Листа» **«План недели»**).
2. **Ноутбук ведущего:** войти как `admin`, открыть **«Лист»** и **«Доска»** на проекторе. По
   ним все видят статус машины.
3. **Клиент для торгового представителя.** Открыть **«Клиенты продавцов»**. Найти клиента,
   закреплённого за участником-представителем. Записать имя: `КЛИЕНТ = ________`.
   Экспорт-менеджер на шаге 3 выберет именно его, иначе представитель машину **не увидит**.
4. **Блок менеджера теплицы.** Открыть **«Управление блоками»**. Убедиться, что за участником
   закреплён блок. Записать: `БЛОК = ________`. Без этого он не сможет править «План недели».
5. **Экспортная фирма с квотой.** Открыть **«Квоты»**. Выбрать фирму, у которой остаток квоты
   больше 0: `ФИРМА = ________`.
6. **План недели.** Открыть **«План недели»**, текущая неделя. Если сетки нет, спросить, эту ли
   неделю реально планируют. Только тогда нажать **«Создать неделю»** (отменить нельзя).
7. **Тестовая машина.** Все значения тестовой машины помечать словом **ТЕСТ** в заметках,
   экспортный код с номером **998**. После теста ведущий отменяет её (часть 6).
8. **Блокировка пароля.** 3 неверных пароля = 30 минут блокировки. После второй ошибки
   участник останавливается и зовёт ведущего. Команда снятия блокировки в UAT_2026-09-17_RU.md.

### Что сказать во вступлении (3 минуты)

1. Цель: понять, заменяет ли платформа Excel в вашей работе, и проходит ли машина весь путь.
2. Сначала одна машина через все отделы по очереди. Потом каждый делает свою работу дня.
3. Данные настоящие. Не уверены, сохранять ли? Спросите ведущего.
4. Любая проблема или идея сразу в **кнопку справа внизу** (Ошибка / Предложение / Вопрос).
5. Вопрос к каждому в конце его шага: **«Так вы это делаете в Excel? Чего не хватает?»**

## Часть 3. Подробный сценарий

Формат каждого шага: **Кто → Где → Делает → Ведущий проверяет → Спросить.**

### Шаг 1. Менеджер теплицы: план

- **Где:** «План недели» → текущая неделя → строка своего блока (`БЛОК`).
- **Делает:**
  1. В ячейку «План» на завтра ввести вес, например `5000`. Появится «План сохранён».
  2. Открыть «План груза и остаток» → сегодня → свой блок → «Планируемый сбор на сегодня» =
     `18000`, примечание `ТЕСТ` → «Сохранено».
  3. Попробовать изменить чужой блок: ячейка должна быть только для чтения.
- **Ведущий проверяет:** свой блок редактируется, чужие нет. Раздел «Запланировано машин» может
  показывать 0 (известный дефект, не ошибка участника).
- **Спросить:** так ли выглядит ваш недельный план? Какие колонки из Excel не нашли?

### Шаг 2. Начальник погрузки: колонка поставки

- **Где:** «Лист» → кнопка **«Добавить отгрузку»** в панели над таблицей.
- **Делает:**
  1. Нажать «Добавить отгрузку». Появится «Создана пустая колонка отгрузки: …». Записать код:
     `КОД-А = ________`. Ввести код в строку поиска, чтобы осталась одна колонка.
  2. Строка **«Блок сбора»**: выбрать `БЛОК`, вес `18100` → Enter.
  3. **«Вес к погрузке»** = `18100`. **«Статус сбора»**: любой вариант. **«Дата сбора»**: открыть
     и подтвердить (запишется сегодня).
  4. **«Экспортный код»**: день `17`, месяц `SP`, номер `998`, блок, год `26` → сохранить.
- **Ведущий проверяет:** после каждой ячейки всплывает «Сохранено». Статус колонки «Черновик».
- **Если кнопки «Добавить отгрузку» нет:** колонку создаёт экспорт-менеджер, начальник погрузки
  заполняет строки 2–4. Записать как находку.
- **Спросить:** это ваша колонка «поставка» из Excel? Что заполняете ещё?

### Шаг 3. Экспорт-менеджер: колонка назначения и объединение

- **Где:** «Лист».
- **Делает:**
  1. **«Добавить отгрузку»** → второй код: `КОД-Б = ________`.
  2. В колонке КОД-Б: **«Страна назначения»** (например Казахстан), **«Клиент»** = `КЛИЕНТ`
     (из части 1, п. 3), **«Импортная фирма»**: любая.
  3. Кнопка **«Объединить»** → подсказка «Нажмите на колонку поставки, затем на колонку
     назначения» → клик по заголовку КОД-А, затем КОД-Б. Панель покажет «Сохраняется: КОД-Б»,
     «Удаляется: КОД-А» → **«Объединить»**.
  4. Нажать на колокольчик в шапке: есть уведомление по машине. «Отметить все прочитанными».
  5. Открыть «Мои задачи»: карточка «Задать назначение» уже в «Сделано сегодня».
- **Ведущий проверяет:** «Черновики успешно объединены». Колонка КОД-А исчезла. В КОД-Б есть
  блок, вес, экспортный код, **дата сбора и статус сбора** (если пусто, это находка).
  Дальше вся машина = **КОД-Б**. Открыть её в «Отгрузки» и записать номер из адреса:
  `ID = ________`.
- **Спросить:** вы так и «женили» поставку с направлением? Удобнее двумя колонками или одной?

### Шаг 4. Отдел документов: фирма, упаковка, контракт

- **Где:** «Лист», колонка КОД-Б.
- **Делает:**
  1. **«Экспортная фирма»** → выбрать `ФИРМА` (не серую «нет квоты»). В «Мои задачи» карточка
     «Выбрать экспортные фирмы» уходит в «Сделано сегодня».
  2. **«Упаковка (гросс-нетто)»** → значок → панель → выбрать шаблон упаковки → сохранить.
     Значок становится «заполненным», видна доля веса фирмы.
  3. **«Контракты»** → значок → панель → создать **разовый** контракт для фирмы: форма спросит
     цену за кг. Записать номер: `КОНТРАКТ = ________`.
- **Ведущий проверяет:** три «Сохранено», оба значка заполнены.
- **Спросить:** контракт, который вы делаете вручную, совпадает с тем, что создалось?

### Шаг 5. Транспорт: машина и водитель

- **Где:** «Лист», колонка КОД-Б; «Мои задачи».
- **Делает:**
  1. **«Номер машины / прицепа»** → окно выбора из автопарка → тягач + прицеп → подтвердить.
  2. **«Имя водителя»** → выбрать водителя; **«Телефон водителя»** заполнится или ввести.
     В «Мои задачи» карточка «Назначить водителя» уходит в «Сделано сегодня».
  3. **«Состояние машины»**, **«Ответственный за авто»**, **«Пункт границы»**, **«Дни в пути и
     темп.»** (`3 / 4`).
  4. «Мои задачи» → карточка **«Передать документы»** → открыть → отметить выполненной.
- **Ведущий проверяет:** номер записан без предупреждения об автопарке, все ячейки «Сохранено».
- **Спросить:** ваш список машин и водителей полный? Кого не хватает?

### Шаг 6. Отдел документов: документы готовы (ворота черновика)

- **Где:** «Лист», колонка КОД-Б, строка **«Документы (13:00)»**.
- **Делает:** выбрать вариант «готово / OK» → Enter.
- **Ведущий проверяет:** заголовок колонки и «Доска»: статус стал **«Таможня ТМ вход»**.
- **Если остался «Черновик»:** ведущий как admin открывает «Отгрузки» → машина → в карточке
  смотрит «Missing / Не хватает» и просит нужный отдел заполнить. Крайний случай: кнопка
  **«Перевести в «Таможня ТМ вход»»** в карточке. Записать, что переход не сработал сам.
- **Спросить:** что для вас значит «документы готовы»? Один вариант или несколько?

### Шаг 7. Отдел документов: таможня ТМ

- **Где:** «Мои задачи», затем «Лист».
- **Делает:**
  1. «Мои задачи» → **«Отправить документы в таможню»** → отметить выполненной.
  2. «Лист» → **«ТМ экспорт. таможня закрыта»** → открыть ячейку → подтвердить (запишется
     текущее время).
- **Ведущий проверяет:** статус **«Таможня ТМ выход»**.
- **Спросить:** вы фиксируете время закрытия таможни? Где?

### Шаг 8. Начальник погрузки: погрузка

- **Где:** «Мои задачи», «Лист», по желанию «Весовщик».
- **Делает:**
  1. «Мои задачи»: карточка **«Отметить начало загрузки»** в колонке «К выполнению».
  2. «Лист» → **«Начало погрузки»** → подтвердить. Статус **«Загрузка началась»**, карточка в
     «Сделано сегодня».
  3. *По желанию:* «Весовщик» → список «Фуры на погрузке» → выбрать КОД-Б → «Добавить паллет»
     два раза (брутто `1200`, ящиков `100`, сорт, подсекция) → сохранить → «Закрыть манифест».
  4. «Лист» → **«Конец погрузки»** (подтвердить), **«Вес нетто (отпр.)»** = `18100`, **«Сорт
     помидора»**, **«Заметки (Солтанмурат)»** = `ТЕСТ`.
- **Ведущий проверяет:** карточка «Заполнить данные загрузки» в «Сделано сегодня».
- **Спросить:** вес нетто вы берёте с весов или считаете? Нужны ли паллеты в системе?

### Шаг 9. Транспорт: выезд

- **Где:** «Лист» → **«Выезд из теплицы»** → подтвердить.
- **Ведущий проверяет:** статус **«Выехал»**. Если у транспорта ячейка не открылась, делает отдел
  документов (записать, у кого сработало). У представителя в «Мои задачи» появилось напоминание
  «Отправить отчёт о продажах».

### Шаг 10. Транспорт: дорога и граница

- **Где:** «Лист», «Карта автопарка».
- **Делает:**
  1. **«Текущее положение машины»** = `ТЕСТ, в пути`; нажать значок карты рядом: окно с
     позицией машины или «нет GPS».
  2. **«Выезд из ТМ»** → подтвердить.
  3. «Карта автопарка» → в поиске ввести номер тягача.
- **Ведущий проверяет:** статус **«Пересёк ТМ границу»**; на карте есть метка или «нет GPS».
- **Спросить:** вы бы смотрели карту вместо звонка водителю?

### Шаг 11. Торговый представитель: страна назначения и продажа

- **Где:** «Лист». Сначала убедиться, что колонка КОД-Б **видна** (представитель видит только
  машины своих клиентов).
- **Делает по порядку**, каждая ячейка: открыть → подтвердить:
  1. **«Въезд в страну»** → статус «Въезд в страну назначения».
  2. Если показываем перегрузку: **«Перегрузка»** = Да **до** следующего шага.
  3. **«Таможня назначения»** → статус «Таможня страны назначения».
  4. **«Время перегрузки»** (если п. 2) → статус «Перегрузка».
  5. **«Прибытие»** → статус «Прибыл в пункт назначения».
  6. **«Город назначения»** выбрать. **«Начало продажи»** → статус «Продаётся».
  7. **«Конец продажи»** → статус **«Продано (ждёт отчёт)»**.
- **Ведущий проверяет:** после каждого подтверждения статус в заголовке меняется.
  «Дата отчёта» статус не двигает, это ожидаемо: двигает сам отчёт (шаг 12).
- **Спросить:** вы получаете эти времена от водителя или от клиента? Что удобнее вносить с
  телефона?

### Шаг 12. Торговый представитель: отчёт о продаже

- **Где:** «Отчёты о продажах» → вкладка **«Нужен отчёт»** → КОД-Б, «Отчёт: нет» →
  **«Открыть отчёт»**.
- **Делает:**
  1. Вкладка **«Продажа»**: валюта (подставится по стране), курс `1`, «Добавить строку»
     (товар, `18100` кг, цена `1.2`), «Добавить расход» (категория, `100`).
  2. Вкладка **«Обработка»** → **«Сохранить отчёт»**.
- **Ведущий проверяет:** «Отчёт сохранён», итоги брутто/нетто, статус **«Отчёт получен и
  завершено»**. Напоминание из шага 9 в «Сделано сегодня».
- **Спросить:** это ваш отчёт из Excel? Какие расходы не нашли в списке?

### Шаг 13. Финансист

- **Где:** «Лист», «Авансы», «Цены».
- **Делает:**
  1. «Лист» → **«Аванс на документы выдан»** = Да.
  2. «Авансы» → вкладка «Авансы» → **«Новый аванс»**: сумма `500`, валюта, цель `ТЕСТ`, привязать
     КОД-Б → сохранить → **«Сверить»**. Статус аванса «Сверено».
  3. «Авансы» → вкладка «Расходы»: добавить таможенный расход по КОД-Б (сумма в манатах).
  4. «Цены» → ввести цену по городу назначения на сегодня.
- **Ведущий проверяет:** аванс в списке со ссылкой на машину; сводка сверху обновилась.
  Страница отчёта о продажах финансисту недоступна: так задумано.
- **Спросить:** суммы сходятся с вашей таблицей? Каких категорий расходов нет?

### Шаг 14. Ведущий: итог на проекторе

1. «Отгрузки» → КОД-Б → вкладка **«История»**: все переходы от «Черновик» до «Отчёт получен и
   завершено» с именами участников. Показать, кто когда что сделал.
2. «Доска»: карточка прошла все колонки.
3. «План недели» → блок `БЛОК` → колонка **«Загружено/Экспорт»** за сегодня = 18 100. Это связь
   плана менеджера теплицы с фактом.
4. Спросить всех: **«Что мешало? Что заняло дольше, чем в Excel?»**

## Часть 4. Своя работа дня (каждый на своём месте, 45 минут)

Настоящие машины сегодняшнего дня. Ведущий ходит по столам.

**Менеджер теплицы.** «План недели»: план по своим блокам на эту и следующую неделю.
«План груза и остаток»: сбор на сегодня. «Внутр. продажи». Вопрос: всё ли из вашего Excel сюда
помещается?

**Экспорт-менеджер.** «Черновики»: «Ввести прогноз урожая» → «Создать черновик» (второй способ
создания машины, из прогноза). «Назначить»: черновик слева, спрос справа, посмотреть
совместимость (не назначать). «Лист»: свои колонки по сегодняшним машинам. «Квоты».
Комментарий к колонке с упоминанием @документы. Вопрос: чего нет в «Листе» из вашего Excel?

**Отдел документов.** «Документы»: сегодняшняя машина → «Готово» или «Нужно заполнить» с
подсказкой, чего не хватает → CMR (Word RU) → «Скачать пакет». «Контракты»: скачать контракт с
печатями. «Экспортные фирмы»: колонка полноты реквизитов. Вопрос: документ совпадает с ручным?

**Начальник погрузки / заместитель.** «Лист»: колонка поставки по сегодняшним машинам.
«Весовщик»: манифест паллет. «План груза и остаток». «Управление автопарком»: добавить прицеп.
Вопрос: остаток по блокам совпадает с реальностью?

**Транспорт.** «Отгрузки», «Доска»: сегодняшние машины. «Лист»: номера, водители, состояние.
«Карта автопарка». Вопрос: чего не хватает по машинам?

**Финансист.** «Авансы»: сегодняшние авансы и таможенные расходы. «Цены». Вопрос: суммы
сходятся?

**Торговый представитель.** «Отчёты о продажах» → «Все мои отгрузки»: только свои клиенты?
«Лист»: свои машины в пути. Вопрос: отчёт заполняется без Excel?

## Часть 5. Если что-то пошло не так

| Симптом | Причина | Что делать |
|---------|---------|-----------|
| Статус не поменялся после ячейки | Открыты другие «ворота» (страна, клиент, фирма, водитель, документы) | Admin: карточка машины → «Не хватает». Заполнить. Крайний случай: «Перевести в …» |
| Ячейка не открывается по Enter | У роли нет права на эту строку | Проверить таблицу в части 7. Если должна открываться, это находка |
| Представитель не видит машину | Клиент машины не закреплён за ним | «Клиенты продавцов» → закрепить клиента |
| Менеджер теплицы не может править план | Блок не закреплён | «Управление блоками» → назначить |
| Клик попадает в соседнюю строку | Закреплённая шапка «Листа» | Панель «Листа» → Настройки → Закрепление → «Без закрепления», или стрелки клавиатуры |
| В ячейку с датой ввели время, а записалось «сейчас» | Известный дефект (F34) | Для теста подходит. Записать, если участнику нужно вводить прошлое время |
| «Документы» показывает «Нужно заполнить» | Не хватает покупателя, страны, водителя или номера | Подсказка перечисляет поля. Заполнить в «Листе», обновить |
| PDF не скачивается | На сервере не настроен LibreOffice | Скачивать Word. Не ошибка участника |
| Пароль не подходит второй раз | Блокировка после третьей ошибки | Стоп. Ведущий снимает блокировку командой из UAT_2026-09-17_RU.md |
| У начальника погрузки нет переключателя сезона в шапке | Известный дефект (нет права на сезоны) | Не ошибка участника. Записать |
| «Запланировано машин» = 0 в «Плане недели» | Известный дефект для погрузки и теплицы | Не ошибка участника |
| Фильтр «Экспортная фирма» в «Отгрузках» пустой | Известный дефект для не-админов | Не ошибка участника |
| Платформа не отвечает | Сервер | Все в Excel. Ведущий: `docker compose ps` и логи бэкенда |
