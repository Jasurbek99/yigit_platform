## Найдено и исправлено (тест красный → зелёный)

1. Код и дата отгрузки брались по UTC: после полуночи в Ашхабаде — «вчерашний» код (3009…) и дата. Теперь `timezone.localdate()`.
2. Карточка «Брутто/нетто»: после выбора шаблона счётчик оставался «0 из 1» — не обновлялась деталь отгрузки.
3. Карточка показывала коды статусов («ok», «in_progress») вместо подписей — не передавались опции, как на Листе.
4. «Выдайте аванс»: в карточке не было ссылки — добавлена «Авансы».
5. Карточка «Проверка качества»: роль «tasks.role.quality_inspector» и поля «transit_days / transport_temp_c / shelf_life_days» без перевода.
6. «Утвердите отчёт» открывалась до отправки отчёта и не имела кнопки. Теперь задача создаётся после отчёта (`depends_on`), кнопка «Утвердить отчёт» — в карточке.

## Замечено, не исправлено

- Продавец на детали отгрузки получает 403 на справочники / квоты / контракты (шум в консоли, страница работает).
- В окне CMR «Место погрузки» не подставляется из отгрузки (нужно выбирать вручную).
- В Planning у тестового рейса X-TEST-0001 остался код E2E01/26 (push прошёл; операции «очистить» в API нет).
- E2E разослал реальным пользователям ~94 уведомления — все удалены при очистке.
