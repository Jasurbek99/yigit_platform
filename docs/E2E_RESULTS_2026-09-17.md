## Findings from the read-only half

Severity is the agents' call, merged across agents. None of these is in the scenario's known-defects list.

1. **MEDIUM: the Dashboard route has no page guard.** Roles without the `dashboard` permission (sales_rep, seller, and loading_dept_head in the live matrix) lose only the menu item. Typing `/` opens the full Dashboard, including the New Shipment and Export Excel buttons. Steps A-01 and A-04.
2. **MEDIUM: the Shipments list and the Sheet call an admin-only firms endpoint.** `GET /api/v1/export/admin/firms/?page_size=200` returns 403 for the loading head, deputy, warehouse chief, weight master, transport, sales rep, finansist and accountant. Their Export firm filter is empty. Step A-03.
3. **MEDIUM: the season switcher disappears for roles without season access.** The header's `GET /api/v1/export/admin/seasons/?page_size=200` returns 403 on every page for loading head, deputy, warehouse chief, weight master, transport, accountant, greenhouse manager and seller. The switcher then does not render. Steps A-06 and X-04.
4. **MEDIUM: Boss Dashboard shows zeros for the export manager and the document team.** The live matrix gives them the page, but all 13 `/api/v1/export/boss/*` calls return 403. The page shows "No data" without an error. Step A-03.
5. **MEDIUM: Sales Rep Coverage is broken for the boss.** The page is in his sidebar, but `GET /api/v1/export/sales-rep-coverage/` returns 403 and the page shows "Failed to load coverage data". Step A-03.
6. **MEDIUM: the Weekly Plan's Truck Allocation section is empty for three roles.** Both of its reads return 403 for the loading head, the deputy and the greenhouse manager, so it reads as "0 planned trucks". Step A-03.
7. **MEDIUM: Pomidor Dükany never appears in a non-admin sidebar.** Its route is missing from `ROUTE_PAGE_MAP` in `frontend/src/utils/permissions.ts`, so only superusers see the link. Roles with the permission can still open it by URL. Step A-02.
8. **LOW: Block Management and Customers call the users endpoint for roles without it.** `GET /api/v1/export/admin/users/?page_size=200` returns 403 for the boss and the deputy, so the manager pickers are empty. Step A-03.
9. **LOW: header requests keep firing after Sign Out** and return 401. Sign-out itself works. Step A-07.
10. **LOW: a logged-in user who opens `/login` gets the login form** instead of a redirect. Step X-11.
11. **LOW: at 400 px the opened sidebar pushes the page sideways** and the page scrolls horizontally. Step X-08.
12. **LOW: the Dashboard subtitle is hard-coded to the 2025/2026 season.** The active season is 2026-2027. Step X-08.

Data findings:

- **No closed season exists.** 2025-2026 is marked Upcoming, so the closed-season read-only mode could not be tested. Step X-02.
- **Work hours and Team leaderboard are switched off for sales_rep** in the live permission matrix. Step A-14.
