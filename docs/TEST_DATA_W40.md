## Как Gaplama считает «доступно»

- **Доступно** = план дня − уже открытые машины + неиспользованный остаток прошлых дней.
- Остаток живёт **7 дней**, у блока **O** только **3 дня**.
- «Tır Aç» работает только в текущей неделе. Машина списывает план того дня, который выбран.
- Путь DraftPool («пул прогноза») без прогноза выдаёт «no forecast». Сначала надо ввести прогноз.
